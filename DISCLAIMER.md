# Clinical Note Tool Disclaimer

## Purpose of This Software

Clinical Note Tool is a documentation support application designed to help clinicians organize clinical information, structure notes, and improve documentation workflow.

This software is intended to function as a productivity aid. It is not intended to replace professional judgment, clinical reasoning, ethical decision-making, or established documentation practices.

## No Clinical Decision-Making

Clinical Note Tool does not provide diagnoses, treatment recommendations, risk determinations, or clinical decisions.

All clinical assessments, interventions, treatment plans, and documentation decisions remain the responsibility of the licensed or qualified professional using the tool.

## Professional Responsibility

Users are responsible for:

* Reviewing all generated or organized content before including it in a clinical record
* Ensuring documentation accurately reflects the services provided
* Following applicable laws, regulations, ethical standards, and organizational policies
* Maintaining appropriate privacy and security practices

The clinician remains responsible for the accuracy, completeness, and appropriateness of all documentation created with assistance from this software.

## Privacy and Data Handling

Clinical Note Tool is designed to support local use and minimize unnecessary transmission of sensitive information.

Users should evaluate the software within their own practice environment and determine whether its use meets their organization's privacy, security, and compliance requirements.

Users should not enter protected health information (PHI) into this tool unless they have determined that doing so is appropriate and consistent with applicable requirements.

## Not a Replacement for an Electronic Health Record

Clinical Note Tool is not an electronic health record (EHR), practice management system, billing system, or medical record repository.

It does not replace systems required by healthcare organizations, insurance providers, licensing boards, or regulatory agencies.

The tool is designed to assist the clinician - not replace the clinician.
